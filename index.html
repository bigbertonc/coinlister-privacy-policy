CoinLister AI Privacy Policy

Effective October 18, 2026

CoinLister AI is a private Windows application being built for its owner's coin listing workflow. This policy describes its current eBay Sandbox connection feature and the planned local handling of coin photographs and listing information. The policy will be updated before those planned features are enabled.

Information handled

  • eBay connection: With the owner's consent, CoinLister AI receives OAuth access and refresh tokens from eBay. It uses them to check authorization and make read-only eBay Sandbox API requests. If eBay's Identity API provides an account name or identifier, the app displays it to the owner during a connection check. The app does not request or store the eBay account password.
  • Coin photographs and listing information: These features are not implemented in the current connection-only version. When added, photographs and listing details are intended to remain on the owner's Windows computer. They will not be sent to an external AI or cloud processing service under this policy.
  • App configuration: The owner enters eBay Sandbox application credentials and the OAuth RuName in a local configuration file. The application credential secret is treated as confidential.

Use and sharing

CoinLister AI currently sends OAuth requests and read-only API requests to eBay to connect and verify the owner's Sandbox account. It does not create, revise, publish, end, or delete listings. The current version does not send coin photographs, listing details, or OAuth tokens to an AI provider, analytics provider, advertiser, or other third party. We do not sell this information.

Storage and security

OAuth tokens are encrypted in the Windows user's Local AppData folder. Their encryption key is stored separately in Windows Credential Manager. App credentials are kept in a local configuration file excluded from Git. The application's eBay requests use HTTPS, and its local interface is bound to the owner's computer.

The current project folder is under OneDrive. The local configuration file may be synchronized by OneDrive according to the owner's account settings. Encrypted OAuth token storage is outside that project folder. Future photograph and listing-data storage must be kept outside synchronized folders to meet the local-only practice stated here.

Retention and deletion

The current app does not apply a fixed retention period. Encrypted OAuth tokens remain until the owner manually deletes the local token file or a new connection replaces them. App credentials remain until the owner removes them from the local configuration file. The app has no disconnect or deletion button yet, and it does not currently store coin photographs or listing information.

The owner can revoke the app's authorization in eBay account settings. Revocation prevents future authorized eBay API requests but does not erase local files. For help locating and deleting locally stored tokens or configuration, contact us below. We will update this policy when deletion controls or coin-data storage are implemented.

This policy website

We will update this notice before enabling new data uses, including coin photograph processing, cloud services, or listing-data storage. The effective date above will change when the policy changes.
