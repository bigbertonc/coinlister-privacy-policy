CoinLister AI Privacy Policy

Effective October 19, 2026

CoinLister AI is a private Windows application for its owner's coin listing workflow. It currently connects to eBay Sandbox and stores local coin photographs and listing drafts. AI identification is optional and runs only when the owner clicks Identify.

Information handled

  • eBay connection: With the owner's consent, CoinLister AI receives OAuth access and refresh tokens from eBay. It uses them to check authorization and make read-only eBay Sandbox API requests. If eBay's Identity API provides an account name or identifier, the app displays it to the owner during a connection check. The app does not request or store the eBay account password.
  • Coin photographs and listing information: The app stores uploaded photographs, draft details, and AI identification results in the owner's local Windows AppData folder. When the owner clicks Identify, the app sends resized, metadata-free renditions of all photographs attached to that draft to OpenAI for visual analysis. Original photo files are not sent. The app does not send listing drafts or eBay tokens to OpenAI.
  • App configuration: The owner enters eBay Sandbox application credentials and the OAuth RuName in a local configuration file. AI identification uses the owner's existing ChatGPT-authenticated Codex session by default. An OpenAI API key is needed only if the owner selects the optional OpenAI API provider. CoinLister does not copy or display Codex authentication credentials.

Use and sharing

CoinLister AI sends OAuth requests and read-only API requests to eBay Sandbox to connect and verify the owner's test account. It does not create, revise, publish, end, or delete listings. Only an explicit Identify action sends that draft's photo renditions to OpenAI. The default Codex provider uses the owner's ChatGPT sign-in; the optional OpenAI API provider uses a separate API key only when selected. OpenAI processes the renditions to return structured identification and listing suggestions. Codex authentication and data handling depend on the ChatGPT workspace; API data controls apply to the optional API provider. The app does not send photographs or drafts to analytics or advertising services, and we do not sell this information.

Storage and security

eBay OAuth tokens and any optional OpenAI API key are encrypted in the Windows user's Local AppData folder. Their separate encryption keys are stored in Windows Credential Manager. Codex manages its own ChatGPT sign-in; CoinLister neither copies those credentials nor stores them in its database. eBay application credentials remain in a local AppData configuration file excluded from Git. Original photographs and the SQLite draft database are also stored in local AppData, outside the OneDrive project folder. The application uses HTTPS for eBay and OpenAI requests; its local interface is bound to the owner's computer.

Retention and deletion

The app does not apply a fixed retention period. The owner can delete an individual local draft in the app; that action removes its database record and associated local photographs. OAuth tokens remain until the owner manually deletes the local token file or a new connection replaces them. App credentials remain until the owner removes them from local configuration. There is no in-app disconnect button yet.

The owner can revoke the app's authorization in eBay account settings. Revocation prevents future authorized eBay API requests but does not erase local files. Removing the app does not itself guarantee deletion of AppData files. For help locating and deleting locally stored tokens, photographs, drafts, or configuration, contact us below. Deleting a local draft does not delete a request already processed by OpenAI; OpenAI's applicable ChatGPT or API data policies govern that processing.
